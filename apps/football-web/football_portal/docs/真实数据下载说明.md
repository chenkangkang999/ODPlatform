## 下载失败与受限来源

首轮有29个GitHub文件请求因TLS EOF失败，系统curl同样连接重置，官方Contents API匿名额度也为0。核验到StatsBomb官方仓库已重定向为`hudl/open-data`后，下载配置改用新官方地址，**29个缺失请求已全部补齐，最终失败数为0**，不需要用户令牌。旧地址保留为来源别名，新的`canonical_url`及每个文件的实际来源列入清单。

SoccerNet MVFouls官方要求NDA与解压密码；SoccerChat实际内容请求返回401。这些没有下载成可用录像。2026最新英超/欧冠VAR仍为官方案例链接，没有冒充已下载的原始训练视频。

## 对42项需求的真实覆盖

已下载视频可以作为**进球、红牌、黄牌**的初步视觉清洗样本；少量第二黄、头球与任意球射门子类只按原始自动标签登记。它们不证明进球有效/无效、牌应不应该出、受牌球员身份，也没有精确越位/门线真值。

35场StatsBomb事件记录实际包含越位、Goal、犯规、手球、黄/红/第二黄、点球、任意球、角球、界外球、球门球、射门、传球、盘带、抢断、扑救、头球、封堵、开球、换人、受伤暂停、阶段结束/开始、阵型及反击等字段。这是**结构化标签/字段覆盖**；部分仅覆盖子情形，不能视为对应视觉模型已具备能力。Goal不提供有效/无效完整二分类，Free Kick不保证区分直接/间接，位置字段不是视觉球场标定。详细42项需求由`event_taxonomy.json`定义。

`coverage_label_counts`是标签出现次数：同一次犯规可能同时有Foul Won和Foul Committed；同一事件可能映射多个需求。因此不能把这些计数直接当作独立犯规、点球或其他事件数量。

当前缺乏经过核验的铲球、假摔、拉推、补时牌、VAR耳机手势、越位陷阱、防线移动、高位逼抢、庆祝、教练、观众事件、天气、烟雾等对应视觉训练样本；不宣称42类已经齐备或已经训练。

## 从清洗开始使用

1. 先查看`infactory/manual_review_queue.csv`，24段均为`pending`。逐段播放，填事件起止时间、真实类型、可见证据与复核备注。受牌人、号码和进球有效性默认空白，不能按邻近人员框猜测。
2. 用VAR复核台选择某段MP4，保存能说明事件的原始关键帧，再记录人工意见。这里的参考线未经过球场标定。
3. 划分数据时按`match_date + home_team + away_team`分组。24段来自13场原比赛；同一比赛的不同片段及其72张派生图片必须进入同一集合。
4. 人工完成框/身份/动作区间标注后，再决定YOLO红黄牌检测与时序事件模型的训练。当前72张图没有YOLO框，不可直接声称可训练。
5. StatsBomb JSON用于先开发事件时间线、分析和LLM的结构化上下文；不当作视觉模型输出。当前模型仍未识别42类。

## 可配置下载工具

工具不含固定来源地址；来源、版本、比赛和默认数量在`data/event_download_plan.json`。默认输出位于项目模块本地目录，也可用`--output`指定。

```powershell
# 安装Web依赖的Python即可；该工具只使用标准库
python football_portal/tools/download_event_data.py

# 调整下载计划/位置/分组或数量；已有完整文件不会重复下载
python football_portal/tools/download_event_data.py --plan football_portal/data/event_download_plan.json --output D:/football-research --groups videos --clips-per-category 3
python football_portal/tools/download_event_data.py --groups events --event-match-limit 3
python football_portal/tools/download_event_data.py --groups images

# 用安装OpenCV的算法Python验证视频、提取预览图并创建人工核验CSV
python football_portal/tools/extract_event_previews.py
```

`manifest.json`记录每个文件的相对路径、原URL、字节数、SHA256、来源、类型和覆盖。更新清单使用临时文件替换。抽帧工具重新运行时会保留人工核验CSV中已填写的内容。

## 使用条件

- [Infactory Soccer Events](https://huggingface.co/datasets/infactory-ai/soccer-events)：作者声明含Infront Italy专有内容，只供非商业研究。原标签由多模态模型自动生成，需要人工复核。视频与派生图片保留本地，不放入公开GitHub。
