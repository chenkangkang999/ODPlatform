## 已取得的真实证据

- 原七页及新增VAR的真实浏览器操作、创建图片示例任务、打开标注、查看分析和本地摘要已验证；390 像素手机宽度无横向溢出，未发现页面脚本错误。
- 真实图片经过 YOLO 推理，读取器记录为 `ODPlatform.FrameSource`，输出 1 个足球、22 个球员、2 个裁判、0 个门将。页面数字与后端一致，标注图、JSONL、CSV 和结果 JSON 可下载。
- 上述模型为本机旧实验 C44 的 YOLOv8s/960 **联调示例**，不是同学确认的最终权重；这是接口执行证据，不是正确率结论。
- 真实视频接口使用 12 帧、6 FPS 的测试短片；素材由真实验证图片重复构成，**不是比赛录像**。步长 2 得到源帧 0、2、4、6、8、10，处理 6 帧；累计足球 6、球员 131、裁判 12、门将 0。视频压缩可能影响各帧输出，累计框不是独立人数。JSONL、CSV 和页面统计一致，完整结果 JSON 再导入保留 6 帧，篡改汇总数字不会影响后端重算结果。
- 导出 VP8 WebM 已在真实浏览器播放，时长 2 秒、尺寸 1280×1280，无页面脚本错误；真实任务取消通过，跨会话视频产物访问返回 404，无 CSRF 的修改请求返回 403。
- 已核对不同浏览器会话不能查看彼此任务，原台账页面仍可访问。
- 当前未配置本项目 LLM 密钥，没有真实 LLM 调用；无密钥提示和本地摘要来源区分已验证。模拟服务测试不等于真实服务商验收。
