# 足球页面与监控改版（当前版本）

页面由Django模板和API提供，原项目文件不改。九个无编号App图标分别进入大厅、检测、VAR、监控、分析、模型、AI解说、档案和设置。

## 统一视觉

三张轮播卡采用同一深绿/暖金球场摄影风格，但分别使用场边足球、俯瞰球场和夜场解说席三张图片，承载检测、数据和解说入口；原平面战术图与紫色AI图案已移除。球场照片是生成的装饰资产，不作为训练素材。深色半透明面板保留。

右侧“我的主场”与球衣偏好已移除，替换为紧凑的观察室进度卡：Django连接、检测队列、项目本地数据文件、人工复核数量及字节数。数字来自监控API，不手填示例数据。两列网格让右卡和左侧轮播画面上下对齐，轮播控制器独占下一行；没有写死面板高度，手机上按顺序堆叠。

## 轮播与配置

默认9秒自动切换，从`.env`的`FOOTBALL_CAROUSEL_SECONDS`经Django渲染读取，JavaScript没有固定9秒定时常量。支持显式暂停/播放、箭头、圆点、鼠标拖动、触摸及键盘。悬停、聚焦轮播控件、拖动、后台或离开总览时暂停；减少动态偏好下停播，保留手动切换。

## 检测画面

框旁仅显示置信度。球员青色、门将紫色、裁判橙色；足球亮黄圆环和准星，并可看原图局部放大。完整类别留在结果表及JSON。统计和类别不会因页面配色而改动，历史图片可从保存框重绘；旧标注视频需新建任务生成新版录像。

## 运行监控与42项

监控展示真实会话任务/失败、复核、已登记调用，以及本地manifest文件检查；按42项目录分别展示视觉样本、仅结构化标注或待取得数据，并显示自动模型状态。可搜索和筛选，不把所有内容挤在首页。当前新增自动事件模型为0，不显示模拟判罚、GPU温度或准确率。

事件目录、数据来源与数量、数据路径、轮播时长和刷新频率均有独立配置入口，见`配置与扩展说明.md`。VAR人工分类和证据提示共用事件目录；自动事件推理与LLM读取VAR证据仍待接入。

## 验证

真实浏览器按实际配置间隔验证自动前进、悬停/按钮暂停恢复、页面切换、减少动态偏好、手动操作、三卡共用照片及5种宽度无溢出。另验证监控真实文件数、42项筛选、真实比赛视频上传/解码/慢放/关键帧与人工导出。没有运行新事件模型，没有调用真实LLM。
